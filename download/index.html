Install or update

  1. Download the installer with the button above.
  2. Run Cutloom-Setup. If Windows shows "Windows protected your PC", click More info, then Run anyway.
  3. Already have Cutloom? Just run the new installer over it. Your projects and settings stay as they are.
  4. After that it's automatic. Cutloom downloads new versions by itself and installs them with one click.
